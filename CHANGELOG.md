# Changelog

All notable changes to Simple Snake Game are documented here.

The project follows [Semantic Versioning](https://semver.org/) for development
tooling. Chrome extension versions use the equivalent `major.minor` form.

## Unreleased

## 1.5.0 - 2026-08-06

### Added

- Pull request coverage reports generated by the Vitest Coverage Report Action.
- Automated checks for version consistency, locale JSON, translation key parity,
  and language registration.
- Dynamic JavaScript percentage and repository size badges.
- Dark color-scheme styling with yellow links for accessible contrast.
- Project changelog and support policy.

### Changed

- Replaced Jest with Vitest while retaining all 48 engine tests and enforced
  coverage thresholds.
- Expanded `npm run check` to validate translations and build the Chrome Web Store
  archive.
- Updated the development runtime to maintained Node.js 22 and 24 releases.
- Updated development dependencies and resolved all reported npm advisories.
- Updated the supported release line to 1.5.x.

### Fixed

- Corrected unsupported Chrome locale directory codes and stale localized
  extension names and descriptions.

## 1.4.0 - 2026-07-02

### Added

- Fullscreen gameplay with a Chrome popup-window fallback.
- Keyboard, touch, pause, restart, and game-over interactions.
- In-app and Chrome Web Store localization for 25 languages, including Simplified
  and Traditional Chinese.
- Automated tests, coverage thresholds, linting, formatting, packaging, CI, and
  community health files.

### Fixed

- Apple placement no longer selects a cell occupied by the snake.
- Fullscreen URLs no longer accumulate duplicate hash fragments.

Earlier history is available in the
[Git repository](https://github.com/doctorlai/snakegame/commits/master/).
