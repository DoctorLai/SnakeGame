# Support

Simple Snake Game is maintained as an open-source project. Community support is
provided on a best-effort basis; there is no guaranteed response time.

## Get help

Before opening an issue:

1. Confirm that you are using the latest Chrome Web Store release or the latest
   revision from the default branch.
2. Review the installation and controls in [README.md](README.md).
3. Search [existing issues](https://github.com/doctorlai/snakegame/issues) for the
   same problem.

For a reproducible bug, open a
[bug report](https://github.com/doctorlai/snakegame/issues/new?template=bug_report.md).
Include the extension version, Chrome version, operating system, exact steps,
expected result, actual result, and screenshots or console output when useful.

Use the
[feature request template](https://github.com/doctorlai/snakegame/issues/new?template=feature_request.md)
for enhancement ideas. Larger changes should be discussed in an issue before a
pull request is opened.

## Security and privacy

Do not disclose vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md)
for private reporting. Data-handling details are documented in
[PRIVACY.md](PRIVACY.md).
